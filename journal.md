Date: 8.30.2026 - Subject: GitHub and Terminal



This week, I learned how to open, commit, and push to a GitHub repo. I also learned that the touch command creates empty files, and is used to update file timestamps.



To prepare a file for updating, use git add <filename> as this will add the updated file to the personal repo.



To commit a new update in GitHub, you must use git commit -m "message".

the -m is to automatically type a message, so you don't need to pull up the in-built editor.



To push, you must use git push -u origin main

This pushes the commit from your personal repo on the computer, to the remote online repo in the GitHub server.
